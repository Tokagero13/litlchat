# Gemini Tray

Микро-браузер с чатом Gemini, живущий в системном трее. Нажал горячую клавишу —
панель выехала у иконки, спросил, прочитал ответ, нажал ещё раз — свернулась.
Без переключения в браузер и без потери того, чем занимался.

Tauri v2 + Rust. На Windows вебвью — WebView2 (Chromium), на Linux — WebKitGTK.

## Что умеет

| Действие | Как |
|---|---|
| Показать / скрыть панель | `Ctrl+Shift+G` или левый клик по иконке в трее |
| Спрятать | `Esc`, повторный хоткей, клик мимо панели, крестик |
| Новый чат | Правый клик по иконке → «Новый чат» |
| Переключиться на закреплённый чат | Вкладка в полосе сверху или правый клик по иконке → название |
| Закрепить открытый чат | Кнопка `+` в полосе вкладок или меню трея (до 3 штук) |
| Открепить | `✕` на вкладке |
| Передвинуть панель | Перетащить за пустое место полосы вкладок |
| Не прятать при клике мимо | Правый клик → «Не прятать при потере фокуса» |
| Масштаб текста | `Ctrl` + `+` / `-` / `0` |
| Настройки | Правый клик → «Настройки…» |
| Выход | Правый клик → «Выход» |

## Вкладки

Сверху панели — полоса вкладок: «Новый чат» и до трёх закреплённых. Клик
переключает чат прямо в панели, `+` закрепляет открытый, `✕` на вкладке
открепляет, двойной клик по названию — переименовывает.

Закрепить можно только беседу, у которой уже есть свой адрес: новому чату
Gemini присваивает его лишь после первого сообщения, и до этого закладка была бы
просто вторым «Новым чатом». Если нажать `+` раньше, полоса скажет об этом. Справа — кнопки настроек и сворачивания, а пустое место полосы
служит ручкой для перетаскивания окна: рамки у панели нет.

## Настройки

Окно настроек (меню трея → «Настройки…») меняет:

Угол и размер применяются **сразу, до сохранения** — панель поднимается рядом,
чтобы было видно, как она ляжет. Фокус при этом остаётся в настройках, а сама
панель убирается, когда вы их закроете.

- **Горячую клавишу** — нажмите на поле и наберите комбинацию, нужен хотя бы
  один модификатор. Применяется сразу, без перезапуска.
- **Где открывать панель** — выбирается кликом по макету экрана: любой из
  четырёх углов (по умолчанию правый нижний), центр или у иконки в трее. У иконки работает только в Windows: ayatana-appindicator
  в Linux координат иконки не сообщает, поэтому там это то же, что «справа снизу».
- **Размер панели** — ползунки, поля ввода и три пресета. Размер, до которого
  вы растянули панель мышью, тоже запоминается — при скрытии.
- **Закреплённые чаты** — до трёх штук: переименование, адрес, порядок.
  Кнопка «Текущий» подставляет адрес открытого сейчас чата; порядок меняется
  перетаскиванием за ⠿ и в том же порядке вкладки идут в полосе и в меню трея.

Если комбинация занята другим приложением, остальные настройки всё равно
сохранятся — в окне появится предупреждение, а горячая клавиша применится при
следующем запуске, когда комбинация освободится.

## Ключи запуска

Там, где системного трея нет, иконки не будет — и если горячая клавиша тоже не
зарегистрировалась, приложение окажется запущенным, но недоступным. На такой
случай:

```bash
gemini-tray --show
```

```bash
gemini-tray --settings
```

При самом первом запуске панель открывается сама — иначе приложение выглядело бы
как не стартовавшее, а войти в аккаунт было бы негде. Дальше она стартует скрытой.

Вход в Google-аккаунт делается один раз: сессия хранится в каталоге данных
приложения, при следующем запуске панель открывается сразу в чате.

Ссылки из ответов Gemini открываются в системном браузере, а не внутри панели —
иначе панель уходила бы на посторонний сайт без пути назад.

## Сборка под Linux

Системные зависимости (Ubuntu / Debian):

```bash
sudo apt-get update && sudo apt-get install -y build-essential pkg-config curl wget file libwebkit2gtk-4.1-dev librsvg2-dev libayatana-appindicator3-dev libdbus-1-dev libssl-dev libxdo-dev
```

Rust:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Запуск и сборка:

```bash
pnpm install && pnpm tauri dev
```

```bash
pnpm tauri build
```

**GNOME:** иконки в трее там нет из коробки — нужно расширение
[AppIndicator and KStatusNotifierItem Support](https://extensions.gnome.org/extension/615/appindicator-support/).
В KDE, XFCE, Cinnamon работает без дополнений.

**WSL2 / WSLg:** системного трея там нет в принципе, а глобальные горячие
клавиши не регистрируются вовсе — у здешнего X-сервера нет полной раскладки,
и попытка падает с `Unable to find keycode`. Запускать через `--show`
и `--settings`. Для нормальной работы нужен настоящий рабочий стол.

## Сборка под Windows

Кросс-компиляции из Linux у Tauri нет. Собирать нативно на Windows:
Rust (MSVC toolchain), Visual Studio Build Tools и WebView2 Runtime
(он уже есть во всех актуальных Windows), дальше та же `pnpm tauri build`.

## Настройки

`settings.json` в каталоге конфигурации приложения:

- Linux — `~/.config/dev.tokagero.geminitray/settings.json`
- Windows — `%APPDATA%\dev.tokagero.geminitray\settings.json`

```json
{
  "url": "https://gemini.google.com/app?hl=ru",
  "hotkey": "CmdOrCtrl+Shift+KeyG",
  "user_agent": "",
  "anchor": "bottom-right",
  "width": 460.0,
  "height": 680.0,
  "pinned": false,
  "pins": [
    { "title": "Команды Linux", "url": "https://gemini.google.com/app/…" }
  ]
}
```

Файл создаётся при первом запуске; обычно его правит окно настроек. `anchor`
принимает `bottom-right` (по умолчанию), `bottom-left`, `top-right`, `top-left`,
`center` и `tray` — последний работает только в Windows. Клавиши в `hotkey` записываются кодами: `KeyG`, `Digit5`, `F9`,
`Space`, `ArrowUp`.

### Если Google не пускает в аккаунт

WebKitGTK — тот же движок, что в GNOME Web, и Google обычно пускает в него
штатно. Если всё-таки появилось «этот браузер или приложение небезопасны»,
пропишите `user_agent` и перезапустите приложение. Подменять User-Agent
без нужды не стоит: заявленный Chrome поверх движка WebKit — расхождение,
на которое проверка реагирует хуже, чем на честный дефолт.

Порядок перебора: сначала актуальный Firefox под Linux, затем Chrome под Linux.

## Как устроена панель

Панель — окно без рамки с **двумя** вебвью: полоса вкладок (локальная
`tabs.html`) сверху и чат Gemini под ней. Встраивать полосу в саму страницу
Gemini нельзя — чужая вёрстка меняется, и накладка ломалась бы на каждом
обновлении сайта.

За это платим включённой фичей `unstable` у крейта `tauri`: несколько вебвью
в одном окне пока за ней. При обновлении Tauri этот участок надо проверять.

Ещё одна платформенная разница: на Windows дочерние вебвью получают настоящие
границы, а на Linux tauri кладёт их в `GtkBox` с `expand = true`, где заданные
границы игнорируются и окно делится поровну. Поэтому под Linux высота полосы
задаётся упаковкой GTK (`pin_tab_bar_height` в `panel.rs`), а под Windows —
обычным `layout()` по событию изменения размера.

## Команды, открывающие окна, должны быть асинхронными

Tauri выполняет **синхронные** команды на главном потоке. Создание вебвью
на Windows ждёт, пока главный цикл прокрутит сообщения, — а из главного же
потока он их не крутит. Итог: окно появляется пустым и висит.

Поэтому `open_settings` объявлена `async`: команда уходит в рабочий поток,
создание окна уезжает в главный, цикл продолжает работать. Из меню трея тот же
код работал и раньше — там обработчик вызывается уже изнутри цикла.

Если будете добавлять команды, создающие окна, делайте их `async`.

## Иконка

Исходник — `src-tauri/icon-source.svg`. Мотив выбран намеренно нейтральным:
логотип Google — их товарный знак, копировать его в стороннее приложение нельзя,
а «искра» давно стала общим обозначением ИИ. Композиция из одной фигуры, потому
что в трее иконка живёт на 16–24 px, и вторая деталь там превращается в грязь.

После правки SVG пересоберите набор:

```bash
python3 -c "import gi; gi.require_version('GdkPixbuf','2.0'); from gi.repository import GdkPixbuf; GdkPixbuf.Pixbuf.new_from_file_at_size('src-tauri/icon-source.svg',1024,1024).savev('src-tauri/icon-source.png','png',[],[])"
```

```bash
pnpm tauri icon src-tauri/icon-source.png && rm -rf src-tauri/icons/ios src-tauri/icons/android
```

Иконку в `.exe` встраивает build-скрипт, а он не перезапускается от правок
в `.rs`. После смены иконки под Windows нужно тронуть `build.rs`, иначе
в бинарнике останется прежняя:

```bash
touch src-tauri/build.rs && pnpm tauri build
```

## Структура

```
src/index.html          окно настроек
src/tabs.html           полоса вкладок в панели
src-tauri/icon-source.svg  исходник иконки
src-tauri/
  capabilities/
    default.json        права локальных окон
    remote.json         страница Gemini: только «спрятать окно», для Esc
  src/
    config.rs           settings.json: чтение, запись, приведение значений
    panel.rs            окно панели: два вебвью, навигация, позиционирование, закладки
    tray.rs             иконка и меню в трее, пересборка меню
    settings_window.rs  окно настроек
    commands.rs         команды, доступные окну настроек
    lib.rs              сборка приложения, события окна, горячая клавиша
```
